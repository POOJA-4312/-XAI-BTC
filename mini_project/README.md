
# 🧠 Explainable AI for Medical Diagnosis (Brain Tumor Classification)

## 📌 Description

The **Explainable AI for Medical Diagnosis** project is a deep learning-based application designed to classify brain tumors from medical images and provide interpretable insights into model predictions. It combines high-performance CNN models with Explainable AI (XAI) techniques to enhance transparency and trust in clinical decision-making.

---

## 🚀 Features

* Brain tumor classification using deep learning
* Multi-class prediction (e.g., glioma, meningioma, pituitary, no tumor)
* High accuracy model with optimized performance
* Explainable AI techniques for model interpretability
* Visualization of prediction reasoning
* User-friendly interface for analysis

---

## 🧠 Technologies Used

* Python
* TensorFlow / Keras
* OpenCV
* NumPy
* Pandas
* Matplotlib / Seaborn
* LIME (Local Interpretable Model-agnostic Explanations)

---

## ⚙️ System Workflow

1. Load and preprocess MRI brain scan images
2. Apply data augmentation to improve model generalization
3. Train custom CNN model for classification
4. Perform prediction on unseen data
5. Apply XAI techniques to interpret results
6. Visualize outputs and explanations

---

## 📊 Machine Learning Approach

* Built a **custom CNN model** for multi-class brain tumor classification
* Achieved **99.34% accuracy** on unseen test data
* Used **data augmentation** and **progressive fine-tuning** to enhance performance
* Applied Explainable AI methods to understand model decisions

---

## 🔍 Explainable AI Techniques Used

* **Occlusion Sensitivity** – Identifies important regions in the image
* **LIME** – Explains individual predictions locally
* **Smooth Gradients** – Reduces noise in gradient-based explanations
* **Saliency Maps** – Highlights pixel importance
